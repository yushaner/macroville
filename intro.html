你的角色

你是城市的规划者 / 观察者。开局设定城市初始参数与地图；运行中用政策杠杆干预经济走向；你也可以全程不干预，只静静看一座城市自己长出来——像培育一个生态。

游戏分三个视角板块（顶部 Tab 切换）：个人视角（典型家庭的储蓄、消费与求职）、企业视角（典型企业的定价、用工与扩产）、政府视角（税收与支出）。三者操作同一座城市、同一批居民与企业，只是你能拧的旋钮和重点看的指标不同——同一个决策在三方身上的后果往往相反，这正是本作想让你体会的。

视角是渐进解锁的：开局你只是一个住户，先管好自家的储蓄与消费；城镇成形后才有资格经营企业；城市长起来才轮到你坐进政府。已解锁的视角不会因城市衰退被收回。

基本规则：经济怎么转

家庭 ↔ 企业 ↔ 政府 的货币与商品循环：这是每月 tick 背后发生的事。

基本规则

  1. 三主体互动：家庭提供劳动力并消费；企业雇佣、生产、给商品定价；政府收税、支出、建基建。三者互相牵动。
  2. 月度 Tick：时间按月推进，每过一个月，主体完成一轮交互，结果聚合成宏观指标。
  3. 四大指标：GDP（总产出）、失业率、CPI（通胀，基期 100）、幸福度；另看财政余额。
  4. 三套旋钮：个人视角 5 个行为旋钮开局可用；企业视角 5 个随城镇解锁；政府视角 7 个政策杠杆随城市解锁，并按年份递进。拖动即改变规则，系统当月的反应会立刻体现在指标上。
  5. 名词即钥匙，决策即钥匙齿：每个旋钮与指标都对应图谱里的一个经济学名词，先解锁名词，旋钮与指标才出现；而名词又只认你拧过的旋钮和你造成的城市状态。锁住的位置会灰显并写明它等的条件与当前完成度，例如"亲手把「加价率」调到 45% 以上（你调到过 30%）"。
  6. 顶部变量条随视角切换：顶栏显示的不是固定几个数，而是你这个身份真正关心的那几个——个人视角看家庭账本（可支配收入、生活水平、家庭财富、抗风险缓冲、入不敷出占比），企业视角看经营盘面（平均利润、产能利用率、平均售价、总营收、岗位空缺率、累计倒闭），政府视角看宏观盘面（GDP、失业率、CPI、财政、基尼、幸福度）。每个变量都带环比箭头与近 48 个月的迷你趋势线；点一下可以打开详情：当前值、这个数怎么来的、区间最高/最低/均值，以及一张累积曲线。
  7. 软提示：指标偏离建议区间时会给出提示与经济含义，但不判输赢——沙盒没有失败结局。
  8. 涌现 > 脚本：没有预设剧情。繁荣、衰退、通胀、崩盘，都是参数与互动自然跑出来的结果。

开局先选一份蓝图：同一个种子，也能长出不同的城

玩法的核心不是挂机等待，而是你先设定一套初始条件 → 家庭、企业与地块之间自己博弈 → 跑出别人跑不出的结果。所以每局开始前，你要先做一次真正的决定：选一份城市蓝图，并决定这一局走几轮循环。

蓝图不只改旋钮：它还改初始人口与地块构成（工业带/商业带各占多少）。所以同一个随机种子，换一份蓝图长出来的城市也不一样。

循环式玩法：个人 → 企业 → 政府 → 再回到个人

一轮循环 = 个人视角 → 企业视角 → 政府视角各主导一段，走完之后回到个人视角，进入下一轮。开局可设 3 / 4 / 5 轮。

之所以要转回来，是因为企业或政府拧过的参数，会反过来改写家庭面对的物价、工资与税率：你在第二轮回到个人视角时，看到的已经不是同一道题。而你在个人视角改掉的储蓄与技能投入，又会通过需求与生产率影响企业，再经由税收与就业影响政府——三者的因果是闭环的。

概念也按轮次分层释放：第 1 轮只放最浅的一层，每进入新的一轮才放出更深一层。同一个名词（比如"工资"）在更深的轮次里会以成本推动、预期这样更细的切面重新出现。

而且解锁是一个一个来的：每月最多点亮 1 个名词，两次解锁之间至少隔两个月。每次都会告诉你"是因为你做了什么"。实测跑 240 个月，解锁动作有 24~57 次——屏幕上一次只出现一条提示，不会一批名词哗啦全亮。

城市发展阶段：8 档细分 + 城市定位

城市不是一开局就建好的。开局你只有中心一小片建成区，随着人口与经济发展逐步向外摊开——重置后从村落重新开始，读档则从存档点继续。阶段细分成 8 档，每档都会改变可出现的设施、企业数量与地图视野。

升级靠人口与存续时间双条件；人口大幅外流也会让城市衰退回落（带滞后，不会在门槛附近反复横跳）。人口流入有两股动力：一是居民满意度（由税后实际工资的购买力、储蓄缓冲、公共服务决定，并被失业率与拥挤成本拖累），二是企业的岗位空缺——只要企业在招人，城市就会持续吸引外来人口。
地图视野随阶段同步拉开：村落只看得见自家门口几条街，全球城市才拉远看到整座城；格子尺寸按面板空间自动缩放，整张地图始终完整显示，不需要缩放浏览器。

城市定位：你长期拧哪一侧的政策，城市就会长成不同的样子——🏭 工业型（产业补贴长期偏高）、🛒 商贸型（贸易开放度高）、🔬 科创型（研发补贴持续投入）、🌳 宜居型（公共支出与福利高、工业弱）、⚖️ 均衡型（各项都不极端）。定位不是按钮，是涌现出来的：判的是你拧到过的旋钮极值，而不是某个月的临时值。它可能长成大城市，也可能停在某个规模——规模和定位各自独立，不同政策组合会导向不同结局。

每个方格都是有脾气的

主界面的格子不是装饰色块。每块地都带一整套属性，并随时间逐月演化：建成没建成、住了多密、值多少钱、被污染成什么样、公共服务够不够用。你拧的每一根旋钮，最后都落到这些数字上。

地图的初始布局按真实的城市规划逻辑生成，而不是随机撒点：中心是 CBD（商业），向外依次是内城居住环 → 住商混合环 → 工业带 → 外围绿带；路网由中心十字主干道、两条环路与支路网格组成；工业与电厂只落在下风向一侧，水厂放在上风向，学校与医院则按 6×6 网格均匀覆盖居住区。所以你看到的"工厂在南边、学校挨着住区"，是规划规则自己长出来的。

三个视角板块

👤

① 个人 / 家庭视角村庄起

旋钮：储蓄率、消费倾向、劳动力参与率、技能投入、风险偏好。

看什么：可支配收入、生活水平、家庭财富、抗风险缓冲。

🏭

② 企业视角城镇起

旋钮：加价率、工资出价、扩产意愿、研发投入、库存策略。

看什么：平均利润、产能利用率、平均售价、总营收。

🏛️

③ 政府视角城市起

旋钮：税率、最低工资、公共支出、产业补贴、研发补贴、贸易开放度、福利支出。

看什么：GDP、就业率、CPI、财政、幸福度、基尼系数。

三个视角共用同一套居民与企业数据：你在个人视角调高储蓄率，企业视角的利润会随之承压——这就是不同决策对不同经济主体的非对称影响。顺序也是叙事：先当住户，再当老板，最后才轮到你决定整座城的税率。

怎么开始

① 开局设定

进场先选蓝图与循环轮数（3 / 4 / 5 轮，推荐 4）。这一步就决定了这一局的走向，不是走过场。

② 速度控制

顶部 ⏸ / 1x / 2x / 4x 控制演化节奏，随时暂停观察。

③ 解锁视角并拖动滑杆

视角随城市成长依次开放（个人 → 企业 → 政府）；右侧旋钮实时生效，看指标与地图如何反应。拧完当场结算解锁。

④ 读图谱，解锁概念

名词不再按月自动出现：每拧一次旋钮、每造成一次经济状态，图谱才可能被点亮一格。点开即学原理。弹窗时自动暂停，关闭后自动恢复运行。

⑤ 界面怎么调

顶栏右侧有界面缩放滑轨（70%~140%），内容多时调小即可，不用再去缩放浏览器；地图与侧栏之间可以拖动分隔条调宽度；右侧三块面板（政策 / 指标 / 图谱）是页签，不再纵向堆叠把页面撑爆。

⑥ 存档：多槽位 + 自己命名

存档不再默认按视角命名——保存时可以自己起名，也可以覆盖已有槽位。读档时打开槽位列表选择要读哪一个，还能重命名与删除。旧版单槽存档会自动迁移到槽位制。

本地运行：在项目目录执行 npm install 后 npm run dev，浏览器打开 http://localhost:5173 即可游玩（需本机 Node 环境）。本沙箱无法对外启动服务，故提供上方「界面预览」静态页供先睹为快。

玩中学经济学（核心特色）

大多数模拟游戏只让你"看到"曲线，MacroVille 让你读懂曲线。当你本局的 CPI 突破 102，会弹出通货膨胀概念卡——定义、本局成因、可试实验、以及公式一并奉上；你拉高税率做对照，就亲手验证了乘数效应。调一次政策，学一个原理。

经济学图谱共 90 个名词：微观 31、中观（产业）30、宏观 29，按5 层深度排列。它们不是按月份排队的——每个名词都带一条解锁条件，判的是三件事：你亲手把旋钮拧到了哪儿（例如"亲手把技能投入调到 50% 以上"）、这些决策把城市带成了什么样（例如"让 CPI 冲到过 106"、"失业率高于 8% 且 CPI 高于 105 连续维持 3 个月"），以及个体博弈跑出来的分化结果（例如"入不敷出的家庭占比超过 35%"）。

挂机点不满图谱，而且一次只来一个。实测什么都不做跑满 240 个月：农耕村落 38 / 90、集市重镇 69 / 90、科教新城 72 / 90——你开的头决定了纯挂机能刷到哪儿；剩下的必须靠你把城市带进更极端的处境。而且每月最多只点亮 1 个、两次之间至少隔 2 个月，不会一批名词哗啦全亮。

它也不是摆设字典——每个名词都挂着一把钥匙，解锁它，右侧仪表盘上对应的旋钮或指标才会亮起。想调最低工资？先在图谱里点亮"最低工资"这一格。反过来，锁住的旋钮会写明它等的是哪个名词、以及那个名词现在的完成度。
